# Road Sign Board Detection System

## Project Overview
A computer vision-based project designed to detect and recognize road signs using an ESP32-CAM and image processing techniques to support safer driving.

## Objectives
- Capture road sign images using ESP32-CAM.
- Process images to identify road signs.
- Explore road sign recognition using computer vision.
- Support safer driving through road sign awareness.

## Technologies Used
- ESP32-CAM
- Python
- OpenCV
- Computer Vision
- Sensors

## Working Principle
1. Capture road sign images using a camera.
2. Process the captured images using computer vision techniques.
3. Analyze image features to identify road signs.
4. Display the detected sign when recognition is supported by the implementation.

## Expected Output
- Road sign images captured by the camera.
- Processed images for road sign detection.
- A detected road sign label when supported by the implemented recognition method.
